
# Grade Calculator

A Python project for calculating student grades.

## Features

- Calculate the average of student grades.
- Check whether a student passes (average >= 10).
- Run automated tests with pytest.

## Installation

```bash
python3 -m pip install -r requirements.txt
```

## Run tests

```bash
python3 -m pytest -v
```
